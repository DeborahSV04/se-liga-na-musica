Se Liga na Música

Descrição do projeto

Este projeto analisa o comportamento dos usuários do serviço de streaming de música na cidade de Springfield e Shelbyville. O objetivo é explorar os dados de reprodução musical e identificar possíveis diferenças nas preferências dos usuários entre as duas cidades, considerando os dias da semana.

Objetivos

* Explorar e preparar os dados para análise.
* Identificar e tratar valores ausentes e registros duplicados.
* Padronizar os nomes dos gêneros musicais.
* Comparar os hábitos de escuta musical entre Springfield e Shelbyville.
* Investigar diferenças nas preferências musicais conforme o dia da semana.

Ferramentas e tecnologias

* Python
* Pandas
* Jupyter Notebook

Etapas da análise

1. Carregamento e exploração inicial dos dados.
2. Limpeza e preparação da base de dados.
3. Tratamento de valores ausentes e duplicados.
4. Padronização dos dados categóricos.
5. Análise exploratória das preferências musicais.
6. Teste de hipóteses para investigar diferenças no comportamento dos usuários.

Principais questões investigadas

* As preferências musicais dos usuários diferem entre Springfield e Shelbyville?
* O comportamento de escuta musical varia conforme o dia da semana?
* Existem diferenças nos padrões de reprodução musical entre as duas cidades?

Arquivo do projeto

* Sprint 2.ipynb — notebook com as etapas de exploração, preparação e análise dos dados.

Conclusão

O projeto aplica técnicas de análise exploratória e preparação de dados para investigar padrões de consumo musical e comparar o comportamento dos usuários entre duas cidades. As conclusões são baseadas nos resultados obtidos durante a análise dos dados.
